# Meeteam RAT-PoC

Вертикальный срез сервиса поиска команд: публичные источники «Хакатоны.рус», Codenrock, Hackathons.pro, HackathonRadar, Kaggle, HackList, Devpost и Devfolio → независимые Go-адаптеры → проверка и нормализация → атомарный локальный снимок → Go API → одностраничная React-лента.

На этом шаге хранилище сделано файловым, чтобы быстро проверить реальный импорт и интерфейс без обязательного Docker. Контракт хранилища отделён от адаптера, поэтому PostgreSQL можно подключить следующим шагом, не меняя код источника.

Итоговая архитектура, отказоустойчивость, обработка краевых случаев и оставшиеся риски описаны в [итоговом отчёте RAT‑PoC](docs/Итоговый-отчет-RAT-PoC.md). Паспорта отдельных источников находятся в `docs/sources`, результаты живых проверок — в файлах `docs/RAT-result-*.md`.

## Что уже работает

- адаптеры «Хакатоны.рус» и Hackathons.pro используют публичные JSON endpoint Tilda вместо headless-браузера;
- адаптер Codenrock рендерит разрешённую публичную страницу каталога в headless Chrome и не обращается напрямую к закрытому `/api/`;
- импортирует текущий и доступные будущие месяцы Codenrock, удаляя дубли между месяцами по slug карточки;
- Hackathons.pro загружает все страницы активного feed, читает детали карточек и отсекает завершившиеся события по дате окончания;
- HackathonRadar читает только разрешённые публичные HTML-страницы базы, извлекает серверный Next.js payload и не обращается к запрещённому `/api/`;
- Kaggle рендерит публичный фильтр активных соревнований и их карточки в Chrome, не требует учётных данных и не обращается к закрытым внутренним endpoint;
- Kaggle импортирует только соревнования с датой закрытия, исключая бессрочные учебные карточки `Ongoing`, которые не являются календарными мероприятиями;
- HackList читает серверный HTML раздела «регистрация открыта», не захватывает архив и уточняет поля карточек по публичному Schema.org `Event`;
- Devpost постранично читает публичный JSON-каталог с явным фильтром `status=open`, поэтому исторические хакатоны не попадают в текущую ленту;
- Devfolio постранично читает публичный search endpoint с фильтром `type=application_open`, который использует сама страница открытых регистраций;
- получает список актуальных карточек и детали каждой карточки;
- разделяет дату начала, срок регистрации и внутреннюю дату актуальности карточки;
- проверяет обязательные поля: название, дата начала, URL карточки и внешняя ссылка;
- ограничивает параллелизм, выдерживает паузу между запросами, повторяет только временные ошибки;
- не удаляет последнюю успешную версию при 403, 429, 5xx, тайм-ауте, пустом или сломанном ответе;
- показывает состояние и статистику каждого источника отдельно;
- позволяет вручную запустить любой адаптер из интерфейса.

## Запуск

Требуются Go 1.24+, Node.js 20+ и установленный Google Chrome или Chromium для адаптеров Codenrock и Kaggle.

```bash
go mod download
cd web && npm install && npm run build && cd ..
go run ./cmd/server
```

Откройте `http://127.0.0.1:8080`. Первый импорт запускается в фоне автоматически.

Для разработки интерфейса в отдельном терминале:

```bash
cd web
npm run dev
```

Vite откроется на `http://127.0.0.1:5173` и проксирует `/api` на Go-сервер.

## Проверки

```bash
go build ./...
cd web && npm run build
```


## API

- `GET /api/events` — сохранённые нормализованные события;
- `GET /api/sources` — состояние и свежесть источника;
- `GET /api/import-runs` — последние циклы и причины отклонения;
- `POST /api/imports/hackathons-rus` — ручной запуск адаптера «Хакатоны.рус»;
- `POST /api/imports/codenrock` — ручной запуск адаптера Codenrock;
- `POST /api/imports/hackathons-pro` — ручной запуск адаптера Hackathons.pro;
- `POST /api/imports/hackathon-radar` — ручной запуск адаптера HackathonRadar;
- `POST /api/imports/kaggle` — ручной запуск адаптера Kaggle;
- `POST /api/imports/hacklist` — ручной запуск адаптера HackList;
- `POST /api/imports/devpost` — ручной запуск адаптера Devpost;
- `POST /api/imports/devfolio` — ручной запуск адаптера Devfolio;
- `GET /api/health` — проверка процесса.

## Переменные окружения

- `HTTP_ADDR` — адрес сервера, по умолчанию `127.0.0.1:8080`;
- `STATE_FILE` — путь к снимку, по умолчанию `data/state.json`;
- `AUTO_IMPORT` — запускать импорт при старте, по умолчанию `true`;
- `IMPORT_CONCURRENCY` — число параллельных запросов деталей, по умолчанию `2`;
- `IMPORT_DELAY_MS` — минимальный интервал между запросами, по умолчанию `250`;
- `CHROME_BIN` — необязательный полный путь к Chrome/Chromium, если браузер не находится автоматически;
- `CODENROCK_TIMEOUT_SECONDS` — лимит одного браузерного импорта, по умолчанию `110`;
- `KAGGLE_TIMEOUT_SECONDS` — лимит одного браузерного импорта Kaggle, по умолчанию `115`;
- `KAGGLE_CONCURRENCY` — число параллельных рендеров карточек Kaggle, по умолчанию `3`;
- `WEB_DIST` — каталог собранного интерфейса, по умолчанию `web/dist`.

## Текущее ограничение PoC

Русские даты извлекаются эвристикой из текста карточки. Адаптер помечает способ разбора в `parsing_notes` и отклоняет карточку, если дату начала или внешнюю ссылку нельзя подтвердить. Поле даты Tilda хранится отдельно как `listing_expires_at`, потому что на разных карточках оно означает срок регистрации, день события или дату, до которой карточку нужно показывать.

Codenrock — более тяжёлый источник: каталог загружается клиентским JavaScript, поэтому один цикл запускает headless Chrome и на текущей машине занимает около 75–90 секунд. При отсутствии браузера, тайм-ауте или изменении DOM источник переходит в `failed`, а последняя успешная версия карточек остаётся доступной.

В Hackathons.pro дата публикации Tilda не является датой мероприятия. Адаптер извлекает диапазон из поля «Даты» или краткого описания. Карточка с формулировкой только «до такой-то даты» отклоняется, потому что достоверную дату начала из неё получить нельзя.

HackathonRadar без авторизации показывает только публичную часть базы. Адаптер импортирует все доступные публичные страницы, фиксируя сортировку по названию для устойчивой пагинации. Скрытые за предложением регистрации или платного доступа записи намеренно не запрашиваются.

Официальный программный API Kaggle требует авторизации, поэтому PoC не хранит токены и не использует внутренние запросы фронтенда. Адаптер рендерит публичный фильтр `active`, извлекает точные даты Start/Close из общедоступных карточек и исключает бессрочные учебные соревнования `Ongoing`. Такой цикл тяжелее обычного HTTP-импорта и на текущей машине занимает около минуты.

HackList отдаёт актуальный раздел серверным HTML, поэтому браузер не требуется. Адаптер доверяет только карточкам внутри блока «регистрация открыта» и проверяет детали через Schema.org `Event`. Карточки без даты или с недоступной детальной страницей остаются в диагностике запуска и не попадают в ленту с выдуманными значениями.

Devpost публикует каталог через JSON endpoint, указанный самим клиентским приложением страницы. Адаптер запрашивает только `status=open`, проходит все страницы последовательно и использует окончание `submission_period_dates` как срок подачи работ. Если число страниц превышает защитный лимит или контракт ответа ломается, импорт завершается ошибкой, а последняя успешная версия остаётся доступной.

Devfolio загружает раздел открытых регистраций через публичный search endpoint. Адаптер повторяет запрос клиента с `type=application_open`, проходит выдачу смещениями по 10 записей и использует точные RFC3339-поля `starts_at`, `ends_at` и `reg_ends_at`. Изменение endpoint или структуры Elasticsearch-подобного блока `hits` обнаруживается проверками контракта во время импорта и не затирает последний успешный снимок.
