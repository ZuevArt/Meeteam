# RAT-PoC: адаптер Hackathons.pro

Дата проверки: 15 октября 2026 года.

## Проверяемый риск

Активный календарь Hackathons.pro загружается динамическим блоком Tilda, дата публикации записи не совпадает с датами мероприятия, а в одном feed одновременно остаются актуальные и уже завершившиеся карточки. Значит, простое чтение HTML или фильтрация по дате записи даст неполный либо неверный результат.

## Решение

Реализован отдельный HTTP/JSON-адаптер:

1. читает опубликованные в странице параметры активного Tilda-feed;
2. загружает все страницы feed с фильтром `all`;
3. получает детальный текст каждой карточки через публичный `getpost`;
4. отдельно извлекает начало, окончание и дедлайн регистрации;
5. проверяет исходную и внешнюю ссылки;
6. отбрасывает уже завершившиеся и неоднозначные карточки;
7. записывает результат через общий контракт хранилища.

## Фактический результат

- два последовательных живых запуска завершились за 5,3 секунды каждый;
- каждый запуск получил 18 карточек feed;
- импортировано 13 актуальных валидных карточек;
- 4 завершившиеся карточки отклонены по `end_at`;
- 1 карточка отклонена, потому что источник указывает только конечную дату пяти этапов без даты начала;
- после повторного запуска в хранилище осталось 13 уникальных ID, дублей нет;
- HTML-сущности в названиях декодируются, ссылки и изображения валидируются;
- источник отображается в интерфейсе отдельной строкой со своей статистикой и кнопкой запуска.

## Доказательство управляемости риска

Риск преодолим без браузерной автоматизации. Специфика Hackathons.pro локализована внутри одного адаптера: остальные источники, модель, API и интерфейс не зависят от Tilda UID, структуры текста или правил фильтрации этого сайта. Неоднозначные данные не угадываются, а явно попадают в журнал отклонений. Повторный импорт идемпотентен по паре `source_id + source_event_id`.

## Следующие проверки

- повторить импорт после обновления календаря и сверить изменившиеся fingerprint;
- добавить метрику доли карточек без даты начала;
- завести алерт при нулевом feed или резком падении числа валидных карточек;
- согласовать допустимую частоту автоматического чтения с владельцем источника перед промышленным запуском.
