# RAT-PoC: первый адаптер «Хакатоны.рус»

Дата живого запуска: 15.10.2026, Europe/Moscow.

## Результат

| Показатель | Значение |
|---|---:|
| Карточек вернул источник | 27 |
| Прошли обязательные поля | 26 |
| Отклонены | 1 |
| Длительность цикла | 7,7 с |
| HTTP 403/429/5xx в контрольном цикле | 0 |

Отклонена карточка «Формула выбора»: в тексте есть срок регистрации, но нет подтверждаемой даты начала. Адаптер не использует дедлайн как дату события и не публикует карточку с выдуманным полем.

## Что доказано

- Список и детали карточек можно повторяемо получать через публичные JSON endpoint Tilda без headless-браузера.
- В живом цикле адаптер нормализовал название, дату начала, формат, ссылку агрегатора и внешнюю ссылку для 26 карточек.
- Разбор различает дату начала, явный дедлайн регистрации и служебную дату ленты Tilda.
- Ограниченный параллелизм и пауза между запросами дают полный цикл менее чем за 10 секунд на текущем объёме.
- Во время RAT‑PoC сохранённый образец ответа использовался для проверки вариантов русских дат, выбора официальной ссылки и сохранения последней успешной версии при отказе. Тестовые файлы не входят в очищенную runtime-версию репозитория.
- React-лента получила через локальный API 26 карточек без ошибок консоли и без горизонтального переполнения на ширине 390 px.

## Что пока не доказано

- Условия сайта ещё нужно проверить отдельно от `robots.txt` и при необходимости согласовать регулярный продуктивный импорт.
- Файловый снимок подтверждает поведение «последняя успешная версия», но PostgreSQL-транзакция из целевой архитектуры ещё не реализована.
- Нужен второй живой цикл с интервалом не менее шести часов, чтобы проверить обновление карточек и отсутствие дублей во времени.
- Для оценки точности требуется ручная сверка всех 26 принятых карточек с первоисточниками. Текущий запуск доказывает техническую извлекаемость, но не заменяет эту сверку.

## Вывод

Гипотеза для первого источника подтверждена частично: технический доступ и повторяемая нормализация работают, 26 из 27 карточек проходят автоматическую проверку. Для завершения RAT по этому источнику остаются правовая проверка, второй цикл и ручная сверка дат и ссылок.
