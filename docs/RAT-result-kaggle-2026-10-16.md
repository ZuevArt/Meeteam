# RAT-PoC: адаптер Kaggle

Дата проверки: 16 октября 2026 года.

## Риск

Kaggle — клиентское React-приложение. Официальный программный API требует авторизации, первоначальный HTML не содержит карточек, а бессрочные учебные соревнования смешаны с ограниченными по времени конкурсами. Дополнительный технический риск на тестовой машине — Go работает под Rosetta, тогда как Chrome должен запускаться в нативной ARM64-архитектуре.

## Проверенная гипотеза

Актуальные карточки можно импортировать без пользовательских учётных данных и без обращения к закрытым внутренним endpoint:

1. отрендерить публичный фильтр `active` штатным headless Chrome;
2. исключить карточки `Ongoing`, у которых нет календарного завершения;
3. параллельно отрендерить публичные детали соревнований;
4. извлечь точные Start/Close, описание, организатора и теги из DOM;
5. нормализовать и сохранить карточки по стабильному slug.

Для macOS на Apple Silicon адаптер определяет Rosetta и запускает Chrome через `arch -arm64`. На остальных платформах браузер запускается напрямую.

## Живой результат

Два последовательных запуска на отдельном временном JSON дали одинаковый результат:

- обнаружено срочных соревнований: 11;
- валидно: 11;
- отклонено: 0;
- сохранено уникальных Kaggle ID: 11;
- формат: 11 online;
- длительность первого цикла: около 59 секунд;
- длительность повторного цикла: около 55 секунд;
- повторный импорт не создал дубли.

Дополнительно публичный список содержал 11 бессрочных учебных карточек `Ongoing`. Они были исключены до загрузки деталей и не считались ошибками.

## Вывод

Риск преодолим. Адаптер не зависит от приватного API или пользовательского токена, получает точные сроки из публичных карточек и укладывается в двухминутный лимит серверного импорта. Основной остаточный риск — изменение DOM Kaggle; в runtime он контролируется лимитами, повтором рендера, живой smoke-проверкой и сохранением последнего успешного снимка. Фикстурные тесты RAT‑PoC удалены из очищенной версии репозитория.
