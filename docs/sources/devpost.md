# Паспорт источника: Devpost

## Назначение

Адаптер добавляет в Meeteam хакатоны Devpost, для которых на момент импорта открыт приём работ.

## Контракт источника

- публичный каталог: `https://devpost.com/hackathons`;
- JSON endpoint, объявленный клиентским приложением каталога: `https://devpost.com/api/hackathons`;
- обязательный фильтр запроса: `status=open`;
- идентификатор адаптера: `devpost`;
- версия контракта: `devpost-public-api-v1`;
- авторизация и headless-браузер не требуются;
- общий `robots.txt` не запрещает обход каталога и endpoint.

## Алгоритм импорта

1. Адаптер запрашивает первую страницу с параметрами `status=open&page=1`.
2. По `meta.total_count` и `meta.per_page` рассчитывает число страниц.
3. Страницы читаются последовательно с общей межзапросной паузой; записи удаляются из дублей по Devpost ID.
4. Для каждой карточки проверяются статус `open`, ID, название, URL и диапазон `submission_period_dates`.
5. Если весь ответ пуст, число страниц выходит за защитный лимит или ни одна карточка не проходит обязательную проверку, цикл считается неуспешным.

## Нормализация

- `source_event_id` — числовой Devpost ID;
- `title` — название карточки;
- `start_at` — начало опубликованного периода подачи работ;
- `end_at`, `registration_deadline_at` и `listing_expires_at` — конец периода подачи работ;
- `start_precision` — `date`, потому что endpoint публикует календарные даты без времени и часового пояса;
- `format` — `online`, если `displayed_location.location` содержит `Online`, иначе `offline` при наличии локации;
- `organizer` — `organization_name`;
- `official_url` и `source_url` — URL хакатона на Devpost;
- `image_url` — публичная миниатюра, включая нормализацию ссылок вида `//cdn...` в HTTPS;
- `tags` — имена из массива `themes`;
- `description` — краткая сводка из организатора, периода подачи работ и призового фонда.

## Защита от сбоев

- максимум три попытки при сетевой ошибке, 429 или 5xx;
- последовательная пагинация и межзапросный интервал `IMPORT_DELAY_MS`;
- защитный предел — 20 страниц за цикл;
- несовпадение заявленного и фактически полученного количества фиксируется предупреждением;
- поломка обязательного контракта завершает импорт ошибкой и не удаляет последнюю успешную версию.

## Ограничения

- endpoint не публикует точное время и часовой пояс дедлайна, поэтому сохраняется только дата;
- начало периода подачи работ не всегда совпадает с датой очного этапа хакатона;
- ссылка отдельной страницы-агрегатора отсутствует: источником и официальной карточкой выступает URL самого хакатона на Devpost;
- изменение endpoint, полей `meta`, `submission_period_dates` или формата английских дат потребует обновить адаптер и повторить живую smoke-проверку.
