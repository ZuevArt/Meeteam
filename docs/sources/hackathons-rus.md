# Паспорт источника: Хакатоны.рус

Дата проверки: 15.10.2026, часовой пояс Europe/Moscow.

## Адреса и способ получения

- Публичная страница: `https://www.хакатоны.рус/`
- Punycode-хост: `www.xn--80aa3anexr8c.xn--p1acf`
- Лента Tilda: `https://feeds.tildacdn.com/api/getfeed/`
- Детали карточки Tilda: `https://feeds.tildacdn.com/api/getpost/`
- Идентификатор ленты ближайших событий: `617755803461`
- Идентификатор блока страницы: `488755787`

Главная HTML-страница содержит пустой контейнер ленты. Браузер получает карточки через публичный JSON endpoint Tilda. Поэтому адаптер обращается к этому endpoint напрямую и не запускает JavaScript.

## robots.txt

На момент проверки корневая страница, карточки `/tpost/` и JSON endpoint Tilda не запрещены в `robots.txt`. Путь `/calendarhackathons` запрещён, адаптер его не использует. `robots.txt` сам по себе не является разрешением на любое использование данных, поэтому перед продуктивным запуском нужно отдельно проверить условия сайта и согласовать частоту запросов.

## Поля

| Нормализованное поле | Источник | Правило |
|---|---|---|
| `source_event_id` | `post.uid` | Обязательное, уникально внутри источника |
| `title` | `post.title` | Обязательное |
| `description` | `post.descr` | Короткий текст, HTML не сохраняется |
| `start_at` | `post.text` | Русская дата после явной подписи или первая дата события |
| `registration_deadline_at` | `post.text` | Только выражение вида «Регистрация до …» |
| `listing_expires_at` | `post.date` | Служебная дата Tilda, семантика между карточками различается |
| `format` | `postparts` и текст | `online`, `offline` или `hybrid` |
| `official_url` | внешняя ссылка в `post.text` | Приоритет у ссылки «Зарегистрироваться»/«Участвовать» |
| `source_url` | `post.url` | Карточка агрегатора |
| `image_url` | `post.image` | Только абсолютный HTTP(S) URL |

## Наблюдавшиеся варианты

- `23–25 октября`
- `с 23 по 30 октября 2026 года`
- `20 ноября — 28 ноября`
- `Дата проведения: 19 ноября 2026 года`
- `Регистрация до 21 октября`

Поле `post.date` нельзя автоматически называть датой начала. В проверенных карточках оно совпадало со сроком регистрации, датой финала либо датой, до которой карточка должна оставаться в ленте.

## Ограничения и меры

- Не более двух одновременных запросов деталей и пауза 250 мс между запросами.
- До двух повторов после первого запроса только для сетевой ошибки, `429` и `5xx`.
- `Retry-After` учитывается с ограничением ожидания в 5 секунд для интерактивного PoC.
- Пустая лента или ноль валидных карточек считается контрактной ошибкой.
- Ошибка карточки не блокирует разбор остальных карточек.
- Неудачный цикл меняет статус источника, но не очищает сохранённые события.
- Автоматического межисточникового объединения по похожему названию нет.
