# Паспорт источника: HackList

## Назначение

Адаптер добавляет в Meeteam хакатоны из публичного календаря HackList, для которых источник показывает открытую регистрацию.

## Контракт источника

- публичный каталог: `https://hacklist.ru/`;
- рабочая область: секция с заголовком «Календарь хакатонов (регистрация открыта)»;
- детальные карточки: публичные пути `/itevents/{slug}/` и `/hackathons/{slug}/`;
- идентификатор адаптера: `hacklist`;
- версия контракта: `hacklist-html-schema-v1`;
- авторизация и headless-браузер не требуются.
- публичный `robots.txt` разрешает обход всех путей (`Allow: /`).

## Алгоритм импорта

1. Адаптер загружает серверный HTML главной страницы.
2. Находит секцию открытой регистрации по смысловому заголовку, а не по CSS-классам.
3. Извлекает уникальные карточки только из этой секции; архивная секция не читается.
4. Публичные детали загружаются с ограниченным параллелизмом и паузой между запросами.
5. Название, дата, описание, изображение, организатор, ссылка участия и теги уточняются по Schema.org `Event` и HTML-метаданным.
6. Карточки без подтверждаемой даты, ссылки участия или доступной страницы отклоняются с явной причиной.

## Нормализация

- `source_event_id` — последний сегмент канонического пути карточки;
- `title` — `Event.name`, с резервным значением из каталога;
- `description` — публичный meta description, ограниченный 420 символами;
- `start_at` и `end_at` — `Event.startDate` и `Event.endDate`; дата без времени интерпретируется в `Europe/Moscow`;
- `format` — `online`, `offline` или `hybrid` по подписи каталога;
- `organizer` — `Event.organizer.name`, если поле опубликовано;
- `official_url` — кнопка «Участвовать», затем `Event.url`;
- `source_url` — детальная страница HackList;
- `image_url` — `Event.image`, затем изображение каталога;
- `tags` — объединение тегов каталога и `Event.keywords` без дублей.

## Защита от сбоев

- максимум три попытки при сетевой ошибке, 429 или 5xx;
- по умолчанию не более двух одновременных запросов деталей;
- общий межзапросный интервал задаётся `IMPORT_DELAY_MS`;
- пустая или исчезнувшая секция открытой регистрации считается нарушением контракта;
- ошибка отдельной карточки не останавливает остальные карточки;
- полный провал валидации завершает импорт ошибкой, поэтому последний успешный снимок сохраняется.

## Ограничения

- отдельный срок регистрации опубликован не у всех карточек и не переносится из свободного текста;
- источник иногда оставляет в открытой секции карточки без даты;
- битая детальная ссылка остаётся отклонением, даже если в каталоге видны название и дата: без детали нельзя подтвердить ссылку участия;
- изменение заголовка секции, структуры `article` или Schema.org потребует обновить адаптер и повторить живую smoke-проверку.
