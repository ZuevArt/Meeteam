# Паспорт источника: Kaggle

## Назначение

Адаптер добавляет в Meeteam актуальные, ограниченные по времени соревнования и хакатоны из публичного каталога Kaggle.

## Контракт источника

- публичный каталог: `https://www.kaggle.com/competitions`;
- фильтр: `listOption=active`;
- сортировка: `sortOption=oldest`;
- идентификатор адаптера: `kaggle`;
- версия контракта: `kaggle-rendered-v1`;
- авторизация и Kaggle-токен не требуются;
- официальный авторизованный API и внутренние endpoint фронтенда не вызываются.

## Алгоритм импорта

1. Chrome рендерит страницы публичного фильтра активных соревнований.
2. Из канонических ссылок `/competitions/{slug}` собираются уникальные slug.
3. Карточки с пометкой `Ongoing` исключаются: это бессрочные учебные соревнования без календарного срока завершения.
4. Детальные страницы оставшихся карточек рендерятся максимум тремя параллельными процессами.
5. Для временной ошибки рендера выполняется один повтор.
6. Из публичной карточки извлекаются название, описание, организатор, точные Start/Close, изображение и тематические теги.
7. Нормализованные события дедуплицируются по стабильному Kaggle slug.

## Нормализация

- `source_event_id` — Kaggle slug;
- `title` — заголовок `h1`;
- `description` — публичный meta description;
- `start_at` — точное значение Start из атрибута времени;
- `end_at`, `registration_deadline_at`, `listing_expires_at` — точное значение Close;
- `format` — `online`, поскольку участие проходит на платформе Kaggle;
- `organizer` — публичная ссылка профиля организатора;
- `official_url` и `source_url` — каноническая страница соревнования;
- `image_url` — публичное Open Graph изображение;
- `tags` — теги карточки и классификация каталога.

## Защита от сбоев

- максимум 10 страниц каталога;
- максимум 3 одновременных рендера по умолчанию;
- отдельный 28-секундный лимит одной попытки карточки;
- один повтор временной ошибки;
- общий лимит импорта 115 секунд;
- пустой каталог и полный провал валидации считаются нарушением контракта;
- при ошибке последняя успешная версия в файловом хранилище сохраняется.

## Ограничения

- Kaggle — клиентское React-приложение, поэтому требуется установленный Chrome или Chromium;
- изменение структуры заголовка, временных атрибутов или ссылок потребует обновить адаптер;
- бессрочные учебные соревнования `Ongoing` намеренно не показываются как события;
- импорт публичной витрины тяжелее HTTP/JSON-адаптеров и занимает около минуты.
