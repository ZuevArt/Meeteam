# Паспорт источника: Codenrock

Проверено: 15 октября 2026 года.

## Точка входа

- каталог: `https://codenrock.com/contests`;
- источник: публичная страница без авторизации;
- идентификатор адаптера: `codenrock`;
- версия контракта: `codenrock-rendered-v1`.

## Почему нужен браузерный адаптер

Начальный HTML содержит каркас страницы, а карточки появляются после выполнения клиентского JavaScript. В `robots.txt` публичный `/contests` разрешён, но прямое обращение к `/api/` и `/_next/` запрещено. Поэтому адаптер не вызывает внутренний API: он открывает обычную страницу в headless Chrome и читает уже отрисованные карточки.

## Контракт DOM

Адаптер опирается на публичные `data-testid`, которые уже используются интерфейсом Codenrock:

- `month-slider-…-btn` — переключатель месяца;
- `contest-card-…` — карточка и slug события;
- `…-name` — название;
- `…-registration-dates` — период регистрации;
- `…-event-dates` — период мероприятия;
- `…-platform-badge` — отметка размещения на Codenrock.

Также читаются первый абзац описания, `img[src]` и `href` карточки.

## Область импорта

1. После загрузки выбираются месяцы не раньше текущего и не дальше 12 месяцев вперёд.
2. Для каждого доступного месяца снимается DOM раздела `main`.
3. Одинаковый slug, встретившийся в нескольких месяцах, импортируется один раз.
4. Уже завершившиеся события отбрасываются.
5. Карточка отклоняется, если отсутствуют slug, название, URL Codenrock или дата начала.

## Нормализация

- `source_event_id` — slug из `/contests/{slug}`;
- `official_url` и `source_url` — публичная карточка Codenrock;
- `start_at` и `end_at` — первая и последняя дата из строки «Мероприятие»;
- `registration_deadline_at` — последняя дата из строки «Регистрация»;
- `format` — `online`, `offline` или `hybrid` по тексту карточки;
- `tags` — ограниченный набор распознанных категорий: хакатон, CTF, ML, AI, Game Jam, олимпиада, акселератор;
- `raw_fingerprint` — SHA-256 нормализуемых полей карточки.

## Отказоустойчивость

- весь браузерный цикл ограничен тайм-аутом;
- нулевой список карточек считается нарушением контракта, а не успешным пустым импортом;
- ошибка одного источника не останавливает следующий источник;
- при ошибке последняя успешная версия Codenrock остаётся в хранилище;
- ручные импорты сериализованы, поэтому два Chrome-процесса не стартуют одновременно.

## Эксплуатационные ограничения

- требуется установленный Chrome/Chromium; путь можно задать через `CHROME_BIN`;
- цикл тяжелее JSON-адаптера и на тестовой машине занимает около 75–90 секунд;
- изменение `data-testid` потребует обновления адаптера;
- карточка Codenrock используется как официальный URL, даже если она агрегирует внешнее событие;
- время внутри дат не извлекается, точность — календарный день в `Europe/Moscow`.
